# CookBook

**CookBook** — это веб-приложение, которое по выбранным ингредиентам предлагает список рецептов.  

---

## ⚙️ Функционал

### 🔹 Гость (неавторизованный пользователь)
- Регистрация
- Авторизация

### 🔹 Авторизованный пользователь
- Поиск рецептов по ингредиентам
- Добавление рецептов в избранное

### 🔹 Модератор
- Все возможности авторизованного пользователя
- Добавление новых рецептов
- Редактирование существующих рецептов

### 🔹 Администратор
- Все возможности модератора
- Управление ролями пользователей (назначение и лишение прав)

---

## 🧩 Модули проекта
- **cookbook-app** — основной модуль приложения (точка входа, конфигурация)
- **cookbook-database-migrations** — миграции базы данных (Liquibase)
- **cookbook-recipes** — функционал работы с рецептами
- **cookbook-user-management** — управление пользователями и ролями
